## Outcome

V1.1 A/B/C is implemented as one local, source-preserving transcript layer:

```text
ASR + subtitle track + burned-in subtitle OCR
  → temporal alignment
  → conservative local fusion
  → Canonical Transcript
  → V1.0-compatible VideoSegment
  → unchanged semantic-v2 + deterministic renderer
```

Explicit ROI is the reliable OCR path. Auto ROI is best-effort and records
`READY` or `UNSTABLE`; it is not a completion gate. Fusion never overwrites
source text. It accepts only traceable local evidence, preserves ASR for
ambiguous sentence-level or unsafe OCR conflicts, and marks those units
`UNRESOLVED`.

An Owner review first recorded
`CHANGES_REQUESTED — FUSION_POLICY_TOO_CONSERVATIVE`. The bounded refinement
keeps that diagnosis in the review history and returns the implementation to
`READY_FOR_OWNER_V1.1_REVIEW` without recording acceptance.

That state was subsequently withdrawn when the Owner identified a full-video
coverage gap: prior real OCR runs covered only 30–70 second windows. The
full-video OCR → Fusion → fresh semantic-v2 → renderer repair below is now

## Previous Fusion policy refinement (superseded for final rework)

The following bullets describe the already executed intermediate policy and are
retained as history. Explicit ROI single-frame acceptance and OCR insertions are
superseded by the active final-rework contract.

- Local diff spans are judged independently only when at least three unchanged
  characters separate them. Nearby changes remain one span.
- Subtitle tracks may supply context-backed short replacements, insertions, or
  deletions. OCR may supply short replacements and internal insertions; OCR-only
  deletion remains rejected.
- Auto ROI still requires stable multi-frame evidence. Explicit ROI accepts the
  same multi-frame evidence and may also use a single frame at confidence
  `>= 0.90`; this is a policy constant, not a quality gate.
- Adjacent equal-length multi-character CJK OCR substitutions remain
  inseparable mixed conflicts. This keeps `于礼` → `干里` unresolved while
  allowing independently separated corrections to be applied around it.
- Free-form provenance now records `accepted_spans` and `unresolved_spans`;
  Canonical Schema and resolution vocabulary are unchanged.
