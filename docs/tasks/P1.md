### TASK-P1-010：Candidate/Gold draft 与 Owner freeze checkpoint

从 P0 已记录 failure taxonomy 建立 1～4 个新 candidate；不得从 Gold transcript 反向
造词，不得复制现有问题。现有 `p0b-r1-rlinf-m` 只作为既有 hard case，不复制计数。

每个 candidate 必须包含：唯一 ID、单一 `video_id`、中文问题、`answerable=true`、

`ART-P1-002 CandidateManifest`；确认前不得运行 B1 Headroom，更不得设计 B2 prompt。

### TASK-P1-020：零 provider 的 B1 Headroom Gate

对既有 hard case 和全部 frozen candidate 使用当前 B1 retrieval/profile/Top-K=5 各运行
一次。保留全部结果，不删除 B1 pass case，不调回答模型。

Qualifying failure 同时满足：

1. pre-frozen；
2. answerable；
3. 当前 B1 `AllNecessaryEvidence@5=false` / `EvidenceUnitRecall@5<1.0`；
4. scorer-only oracle 证明 `search_video` rewrite 或 `inspect_segments(radius=1|2)` 能新增
   至少一个缺失 Gold unit；
5. 恢复路径不读取 Gold 作为 runtime context、不跨视频、不要求 VLM。

输出所有 case 的 B1 result、Gold delta、qualifying reason 和 Headroom count。

- count `<2`：终止 `NO_GO_INSUFFICIENT_HEADROOM`，不得施工以下 B2 tasks。
- count `>=2`：记录 `HEADROOM_PASSED`，才可进入 TASK-P1-030。

R2/R3 retrieval 与权威 segment source；不得创建万能 Tool、任意时间范围、模型选 Top-K

### TASK-P1-040：Trace 与 run-local Evidence Gate

transcript。完成一个 offline success replay 和一个 failure/recovery replay。
